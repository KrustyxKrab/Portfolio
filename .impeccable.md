## Design Context

### Users
The personal website serves clients, the community, and people interested in Silas' work and personality. Projects, About and Contact must be easy to find; Journal, Photos and personal details invite exploration.

### Brand Personality
Warm, personal, playful and carefully crafted. An inviting retro computer world that is memorable and easy to use.

### Aesthetic Direction
Silas OS: a sculptural cream Macintosh-inspired computer on desktop, with space around the physical housing. The user approved the Mac in docs/vision/silas-os-vision-01.png. Plan a Three.js housing with a real HTML screen. The classic desktop has a top menu bar and individual desktop icons, with no bottom dock or taskbar. Mobile fills the available viewport without a drawn phone housing, while retaining the same dimensional pixel icons and retro visual language. The user selected the LinkedIn cover Hamburg Silouette.png in the project root as the primary art direction for the wallpaper and the whole website's pixel style: finely detailed Hamburg harbor architecture, honey/apricot evening light, slate-gray sky, warm brick buildings and stepped water reflections. Exclude its white letterboxing. Match the fine pixel density across UI artwork and icons; the user's chunky pixel-object references still guide icon silhouettes and perspective. Preserve the warm dimensional cream physical Mac. Present desktop and mobile as separate clean screens without editorial headers or design-board annotations when showing the next visual revision.

### Design Principles
- Present projects, personality and contact clearly within the playful OS experience.
- Keep desktop hardware dimensional and the actual interface legible, accessible HTML.
- Mobile is a full-viewport interface with the same icons; no outer device frame.
- Use Astro, static content and small JavaScript modules; load Three.js only for desktop and render its scene on demand.
- Prioritize responsive interactions and a coherent icon family over unnecessary effects.

## Pixel Studio Context

The existing pixel studio is a separate tool for creating and refining a Hamburg panorama with the assistant. Its interface stays a calm, clear, German-language atelier. High native resolutions, editable pixels and reproducible drawing instructions matter. Its artwork workflow has these separate principles:

- Give the artwork the largest, quietest surface.
- Use a warm paper background, restrained controls and precise typography.
- Keep native raster dimensions distinct from viewing zoom and export enlargement.
- Keep every color, layer and pixel editable and reproducible without image generation.
