# Macintosh model notes

The Macintosh 128K FBX source was supplied by the user. The converted GLB contains the full assembly from 65 source meshes: computer, brightness control, keyboard, keycaps, mouse, and cables. It is 3,393,356 bytes (about 3.4 MB), with textures embedded. The model is normalized to 10 units high at the monitor, uses shared materials, and has welded geometry. The runtime loads it with Three.js `GLTFLoader` on desktop only.

The first-session intro shows the complete computer kit, then moves to a large view of the display. A DOM homography aligns the real HTML interface with the model screen. After the intro, the camera makes a subtle orbit; the model itself stays static. **View → Computer ansehen** toggles the overview. The intro respects reduced-motion preferences.

No license file was included with the FBX supplied in the user folder. The current Apple mark and model presentation are drafts, and legal clearance is pending.
